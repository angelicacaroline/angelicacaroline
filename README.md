# 🤠 Bem vindo ao meu GitRanch

> *"Existem dois tipos de pessoas no Velho Oeste: as que programam com calma e as que dão `git push --force` e passam o resto da vida fugindo da lei."* — Arthur Morgan

Sou uma **Machine Learning Engineer** focada em **Back-end** e apaixonada por **Sistemas Embarcados**. No meu dia a dia, eu cuido do meu código como quem cuida de um rancho: cerco os bugs, domino dados em qualquer território de negócios e garanto uma infraestrutura de servidor firme como cerne de aroeira. No meu repositório, o sistema é bruto e o código é limpo.

### O Plano do Dutch

> *"I have a plan! Só preciso de um pouco mais de tempo, de café e de dados limpos. Confia no processo, que o deploy em produção sai."* — Dutch van der Linde

* **Machine Learning (Rotação de Cultivo):** Treinar modelo preditivo é igualzinho a cuidar da terra. Se você sobrecarregar o solo com o mesmo nutriente, dá `Overfitting`. Tem que diversificar a base de dados para a colheita vir forte.
* **Sistemas Embarcados (Gambiarra de Sítio):** Lidar com Arduino e eletrônica de baixo nível é a arte de consertar trator velho com arame. Se o código não compilar, a gente mexe no conector da protoboard e torce pra dar certo, uma hora dá sinal de vida.
* **Back-end (Alicerce do Silo):** Java e Python no back-end são as vigas que sustentam o armazém de grãos. O front-end pode ser bonito, mas se o silo rachar, a safra inteira (os dados) se perde.

### Meu Alforje de Tecnologias

O **Python** é o meu cavalo de confiança e o **Arduino** é o meu passatempo favorito, sempre que posso estou criando engenhocas para o rancho.

* **A Divinação de Safras:** `Python` (`Scikit-Learn`, `Pandas`, `XGBoost`)
* **A Viga do Celeiro:** `Java` (Robustez no Back-end)
* **Automação no Pasto:** `Arduino` (eletrônica em geral)
* **Carpir o Mato Alto (Código Legado):** Não tenho medo de pegar no pesado. Enfrentar código legado em `COBOL` é igualzinho a carpinar um pasto de mato alto: dá trabalho, mas no final o lote fica limpinho, limpinho.
